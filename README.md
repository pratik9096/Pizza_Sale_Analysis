
# Pizza Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard built to analyze pizza sales data and understand business performance through data visualization.

## Technologies Used
- Power BI
- SQL

## Key Features
- Revenue and order analysis
- KPI tracking
- Sales trends visualization
- Pizza category and size analysis
- Top-selling pizza analysis
- Interactive filters and slicers

## Project Files
- Power BI Dashboard (.pbix)
- Dashboard Screenshots
- SQL Queries

## Objective
To transform raw pizza sales data into meaningful insights that help understand sales performance and support data-driven business decisions.
